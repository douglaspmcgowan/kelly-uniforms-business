# M&T Uniforms storefront prototype

An interactive, static prototype of the client-first replacement storefront. It proves discovery, fit/options, request preparation, and human ordering fallback using recovered public evidence. It contains no authenticated OpenCart/Ecwid data and processes no payment.

```powershell
npm install
npm run dev
npm test
```

`npm test` validates the exact notice, seven product fixtures, public asset hashes, safety boundaries, responsive/reduced-motion rules, TypeScript, and the production build.
